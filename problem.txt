# ソクメイシ - 問題管理 (problem.txt)
# 運用ルール:
# - 開発中に見つかった問題(想定した動きをしない、デザイン崩れ等)や修正要望は全てここに記録する
# - 修正プロセス(CLAUDE.md「問題修正プロセス」参照・省略禁止):
#   問題共有 → problem.txtに記録 → 原因を徹底調査 → 原因特定 →
#   タスクを切り出しprogress.txt/manual-work.txtに追加 → 修正作業 → 解決済みに更新
# - 問題IDは P-001 から連番で付与する
# - 原因調査・特定・切り出しタスクの欄を埋めずに修正作業を開始してはならない
# - テストデータの変更等で問題を回避しただけの場合は「解決済み」にしない

## P-001: 全ユーザーの名刺データが未認証で一覧取得できる
- 記録日: 2026-11-23
- 状態: 修正中
- 発生箇所: Firestore 本番ルール / cards コレクション
- 問題内容:
  想定した動き: 名刺は URL を知っている人が1枚ずつ見られるだけ
  実際の動き: 誰でも cards を一覧取得でき、氏名・名刺画像・SNS が取得できる
- 再現手順:
  1. 未認証で GET https://firestore.googleapis.com/v1/projects/sokumeshi-58f06/databases/(default)/documents/cards?pageSize=1 → 200
- 原因調査: リポジトリに firestore.rules がなく、本番ルールが list を許可している(REST で 200 を確認。取得は1件・1項目に限定)
- 特定した原因: 本番ルールが cards の list を未認証で許可している
- 切り出したタスク: W1, 1-10, 2-2, W2, 2-3
